## 🔧 Easy Customization

### **Change Colors (5 minutes):**

Edit `assets/css/chatbot.css`:

```css
/* Replace blue with your brand color */
.bg-blue-600 {
  background-color: #your-color !important;
}
```

### **Add New Responses (2 minutes):**

Edit `js/chatbot.js` in the knowledge base:

```javascript
newTopic: {
  question: "Your question here",
  answer: "Your detailed answer here",
  keywords: ["keyword1", "keyword2", "keyword3"]
}
```

### **Update Contact Info (1 minute):**

Search for phone numbers and emails in the responses and update them.
