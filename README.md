## 🚀 Quick Start

### **Prerequisites**

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### **Installation & Setup**

```bash
# Clone the repository
git clone https://github.com/Romega-Solutions/romega-solutions-website.git

# Navigate to project directory
cd romega-solutions-website

# Open in browser (or use live server)
open index.html
```

### **Development Workflow**

1. **Component Development**: Edit reusable components in `/components/`
2. **Styling**: Customize design system in `/assets/css/styles.css`
3. **Functionality**: Extend JavaScript features in `/assets/js/main.js`
4. **Content**: Update page content in respective HTML files

## 🚀 Deployment Guide

### **Static Hosting (Recommended)**

```bash
# Build for production
npm run build

# Deploy to hosting service
# - Netlify: Drag & drop dist folder
# - Vercel: Connect GitHub repository
# - GitHub Pages: Push to gh-pages branch
```

### **Traditional Web Server**

1. Upload all files maintaining folder structure
2. Configure web server to serve `index.html` as default
3. Ensure proper MIME types for all file extensions
